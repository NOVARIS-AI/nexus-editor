# NEXUS Notifications\n\nIn-app notifications are created by database triggers for follow requests, accepted follows, new followers, post likes and post comments. Each notification is visible only to its recipient through row-level security. The mark-read RPC verifies the authenticated recipient and supports single-item and mark-all operations. The app page supports All/Unread filters, refresh, read state and a shortcut to review follow requests.\n\nPush notifications, realtime subscriptions and email delivery are not included in this stage. Apply the 202611050006_notifications.sql migration in the dedicated NEXUS Supabase project before expecting live events. No deployment or build test was run.
